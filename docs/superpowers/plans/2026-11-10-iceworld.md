# IceWorld Implementation Plan

> **For agentic workers** use superpowers:executing-plans for inline execution.

**Goal** Deliver six usable GH examples, a validated index and two approval systems.

**Architecture** A portable `Miki.IceWorld` project generates prisms and rail paths. `Miki.IceWorld.Grasshopper` converts these into Rhino Breps and exposes components and an enforced bake entry point. Repository scripts validate the catalog and GitHub approval eligibility.

**Tech Stack** .NET 8, RhinoCommon 9, Grasshopper 9, Python 3.12 standard library, GitHub Actions and JavaScript.

**Spec** `docs/superpowers/specs/2026-11-10-iceworld-design.md`

## Global constraints

- Metre source units, test-assumption dimensions, maximum 5000 generated parts.
- Keep the existing BIM contract intact.
- Explicit independent validation statuses and no unverified native claims.
- GH recompute previews geometry. Bake requires a button edge and policy approval.

## Review focus

- Nonfinite numbers and unknown parameter names must fail before geometry generation.
- Rotated/return flights must preserve rail and platform continuity.
- Millimetre documents must scale metre source lengths correctly.
- Repeated bake triggers must preserve existing model objects.
- Stale workflow runs, untrusted contributors and policy changes must never receive automatic approval.
